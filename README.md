# PRISM — Слепое обнаружение изменений в сигнале 
(*Prediction-Residual Inter-Segment Matching*)

Алгоритм раскладывает сигнал на две части: **содержание** (предсказуемая часть) и **след тракта** (остаток, который предсказать нельзя). Изменение ищется во втором.

## Идея

Эталона нет, поэтому сигнал сравнивается сам с собой. Все части нетронутого сигнала прошли один и тот же путь: источник → микрофон или приёмник → АЦП. Если какую-то часть вставили или обработали, её «почерк» будет отличаться от остальных, даже если содержание выглядит естественно.

1. Скользящая AR-модель (линейное предсказание) убирает из сигнала содержание. В **остатке** остаётся шум и следы тракта.
2. **Механизм 1, «отпечаток тракта».** Каждое окно (128 мс) описывается признаками остатка, и для каждого признака считается, насколько окно отличается от типичного окна этого же сигнала (устойчивая z-оценка по медиане).
3. **Механизм 2, «матрица взаимного предсказания».** AR-модель каждого сегмента (256 мс) предсказывает все остальные сегменты. Получаются две матрицы:
   - по **сигналу**: смена содержания;
   - по **остатку**: смена тракта.

   Границы находятся детектором «шахматной доски», «чужие» сегменты — по строкам матрицы, копии — по почти идеальному совпадению остатков.
4. **Правило решения.** Граница только в матрице содержания означает естественную смену (сменилась речь или режим работы). Граница в матрице тракта, аномалия отпечатка или копия означают **изменение**.

| Признак (механизм 1)                     | Что выдаёт                          |
| ---------------------------------------- | ----------------------------------- |
| белизна и форма спектра остатка, доля ВЧ | фильтрацию, чужой АЦП               |
| связи соседних отсчётов остатка          | интерполяцию и ресемплинг           |
| шумовой пол (только в паузах)            | чужое устройство, шумоподавление    |
| плато на максимуме                       | клиппинг                            |
| гребёнка уровней (спектр гистограммы)    | изменение громкости после оцифровки |
| амплитуда и фаза фона сети 50/60 Гц      | вставку из другой записи            |

**Устойчивость.** Спектры и автокорреляции считаются как медиана по 8 частям сегмента. Поэтому редкие удары и щелчки (тоже содержание) не принимаются за смену тракта. Пороги заданы в единицах разброса самого сигнала, поэтому от природы сигнала они не зависят.

## Тесты

Синтетические 20-секундные записи трёх видов: речеподобный сигнал, радиосигнал (BPSK на 3 кГц), датчик вибрации. Каждая запись проходит через «устройство»: шум, фон сети, антиалиасинговый фильтр, 16 бит. В каждую вносилось одно изменение длиной 2–3 с. Склейка делалась фрагментом **той же природы**, но с другого устройства. Для каждого случая взято 10 случайных сигналов. Результат считается верным, если найденное место совпало с истинным с точностью ±0,35 с.

| Случай                         | Речь  | Радио | Датчик | Чем найдено                                          |
| ------------------------------ | ----- | ----- | ------ | ---------------------------------------------------- |
| Чистый сигнал (ложные тревоги) | 0/10  | 0/10  | 0/10   | —                                                    |
| Естественная смена содержания  | 0/10  | —     | —      | граница только в матрице содержания → «естественно»  |
| Склейка с другого устройства   | 10/10 | 10/10 | 10/10  | матрица тракта (граница + «чужой участок»), фон сети |
| Фильтр НЧ 4 кГц                | 10/10 | 10/10 | 10/10  | матрица тракта, белизна остатка, шумовой пол         |
| Усиление ×1,5 после оцифровки  | 10/10 | 10/10 | 10/10  | гребёнка уровней                                     |
| Клиппинг                       | 10/10 | 10/10 | 10/10  | плато на максимуме, матрица тракта                   |
| Копирование фрагмента          | 10/10 | 10/10 | 10/10  | совпадение остатков (корреляция ≈ 1,0)               |
| Ресемплинг +3 %                | 10/10 | 10/10 | 10/10  | матрица тракта                                       |

Всего 220 прогонов: все изменения найдены, место указано верно в 100% случаев, ложных событий ноль. Рисунки с матрицами для каждого случая лежат в `figures/`.

**Что пришлось исправить по ходу тестов** (это и есть главные уроки):
- «Выигрыш предсказания» убран из решающих признаков: он зависит от содержания (паузы и речь) и давал ложные тревоги.
- Шумовой пол меряется только в окнах, которые не громче самых тихих мест больше чем на 5 дБ. Порог по доле окон (например, «30% самых тихих») ломался, когда копия закрывала паузы.
- Модели строятся по медианному спектру. Без этого удары в сигнале датчика «перетягивали» модель и выглядели как смена тракта.

## Ограничения

- Алгоритм ловит **неоднородность**. Если весь сигнал целиком прошёл одну и ту же обработку, внутри он однороден, и это не обнаруживается.
- Копия с того же устройства не меняет тракт. Её находит только проверка совпадения остатков, и только если копия не была дополнительно обработана.
- Порог гребёнки работает лишь для сигнала, лежащего на сетке квантования (сырые отсчёты АЦП, WAV).
- Тесты синтетические. На реальных данных пороги стоит перепроверить на заведомо чистых записях.
